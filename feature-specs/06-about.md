# Feature Specification — About Section

## Feature ID

06-about

---

# Purpose

The About section should introduce the person behind the code.

Instead of listing facts, it should tell a story that explains how curiosity became a passion for programming.

The visitor should leave understanding

- Who Mantu Yadav is
- Why he started programming
- How he learned
- What motivates him today

This section should create an emotional connection while remaining professional.

---

# Design Philosophy

The About section should feel

- Personal
- Authentic
- Interactive
- Story-driven
- Easy to read
- Visually engaging

Avoid

- Large paragraphs
- Resume-style writing
- Generic AI-generated text
- Buzzwords
- Walls of text
