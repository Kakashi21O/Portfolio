# Projects Section

## Goal

The Projects section is the heart of the portfolio.

It should immediately demonstrate real-world engineering experience instead of simply listing repositories.

Every project must feel like a premium case study.

---

# Layout

Desktop

Two-column responsive grid.

Each project displayed as a large glassmorphism card.

Spacing between cards: 48px

Rounded corners: 24px

Soft border

Backdrop blur

Gradient overlay on hover.

Mobile

Single column layout.

Cards stack vertically.

No horizontal scrolling.

---

# Card Structure

Every project card contains

• Project Cover Image
• Project Name
• One sentence summary
• Technologies
• Features
• Architecture button
• GitHub button
• Live Demo button
• View Case Study button
