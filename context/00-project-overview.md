# My Story

My programming journey started unexpectedly.

When I was in 4th grade, our PT teacher occasionally allowed our class to visit the computer lab.

One day I noticed a senior student writing HTML.

I didn't understand what he was building, but watching code create something on the screen fascinated me.

That day I went home and repeatedly asked my parents to buy me a laptop.

Eventually they did.

That laptop completely changed my life.

I started learning Python during 9th grade.

Initially I learned variables, loops, operators, conditions, and functions.

By 11th grade I had become comfortable with object-oriented programming and Python fundamentals.

Later I became deeply involved in Discord communities where I built numerous automation tools, experimented with APIs, event-driven systems, WebSockets, debugging, and backend logic.

Those years strengthened my programming and problem-solving abilities.

Today I'm expanding into modern web development while continuing to improve my backend engineering skills.
