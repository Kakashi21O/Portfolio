# Developer Story

Programming became interesting in **4th grade** after watching a senior student write **HTML** in a school computer lab.

Curiosity quickly turned into a goal, leading to the request for a personal laptop to learn programming independently.

The journey began seriously in **9th grade** with **Python**, eventually expanding into

- Backend Development
- Automation
- APIs
- WebSockets
- Linux
- Docker
- DevOps
- Artificial Intelligence

The motivation has always been understanding how systems work and building practical solutions rather than simply writing code.

Problem-solving through logic, experimentation, and pattern recognition is preferred over memorizing syntax or following tutorials blindly.
