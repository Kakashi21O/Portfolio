# Roadmap

## Purpose

This roadmap defines the planned evolution of the portfolio.

The portfolio should continuously improve as new skills, projects, and experiences are gained.

It should remain a living project rather than a one-time showcase.

---

# Vision

The long-term goal is to transform this portfolio into one of my strongest technical projects.

The website should not only display my work but also demonstrate how I think, solve problems, and build software.

Every major improvement should enhance one or more of the following:

- User Experience
- Performance
- Accessibility
- Storytelling
- Technical Quality
