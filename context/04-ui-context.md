# UI Context & Theme

## Purpose

This document defines the complete visual language of the portfolio.

Every page, component, animation, icon, spacing, and interaction must follow these rules.

The portfolio should feel handcrafted rather than template-based.

---

# Design Philosophy

The UI should communicate

- Passion
- Curiosity
- Precision
- Creativity
- Professionalism

The design itself should demonstrate engineering quality.

Every interaction should feel intentional.

---

# Theme

Primary Theme

Dark

Never provide a light mode unless explicitly requested.

Dark should feel comfortable for long viewing sessions.

---

# Color Palette

Primary Accent

Electric Blue

Purpose

- Buttons
- Active Links
- Highlights
- Cursor
- Interactive Elements

Secondary Accent

Purple

Purpose

- Gradients
- Hover States
- Background Lighting

Support Colors

White

Soft Gray

Slate

Transparent Glass

Avoid

Pure black

Pure white

Highly saturated rainbow colors

Large color palettes

---

# Background

The background should feel alive without distracting from the content.

Inspired by

https://aakarsh-devhq.vercel.app/

Use

Subtle gradients

Soft lighting

Mouse reactive glow

Depth

Blur

Noise

Floating particles

Very slow movement

Background should react slightly to cursor movement.

Never overpower the content.

---

# Glassmorphism

Use only where appropriate.

Examples

Navigation

Cards

Dialogs

Music Player

Settings

Use

Blur

Transparency

Soft borders

Soft shadows

Avoid excessive blur.

---

# Typography

Typography should be one of the strongest visual elements.

Hero

Very large

Bold

Clean

Readable

Section Titles

Large

Simple

Minimal

Paragraphs

Easy to read

Good spacing

Maximum readability

Avoid decorative fonts.

# Layout

Use generous whitespace.

Every section should breathe.

Avoid cramped layouts.

Content width should remain readable.

---

# Grid System

Maintain consistent spacing.

Desktop

Wide layout

Mobile

Single column

Never break alignment.
